# Rag_Projects

RAG Projects | Retrieval-Augmented Generation

A hands-on collection of Retrieval-Augmented Generation (RAG) projects built using Python, LangChain, vector databases, embeddings, and Large Language Models (LLMs).
This repository documents my journey of learning and implementing RAG, starting with foundational applications and gradually progressing towards advanced AI-powered systems.
